## 2. 证据基线（研究组产出，引用链）

**权威实测链**（取代已被证伪的"DG0SNC 研究"——多轮检索确认该文献不存在，本设计全程撤回）：

- Owen Duffy VK1OD/VK2OMD（squashpractice.com，量热法+VNA，2021–2026 系列）：loss ∝ 1/N_primary；单 FT240-43 2:14 ≈75%；FT114-43×2 量热 90.5–93.4%@50W FT8；2643 芯 2:14+100pF 三源 ≈89–91% 平坦；43 料 30MHz 处 0.7dB；次级入盒寄生电容 2.7→6.0pF；43 热饱和 ≈2000 高斯、B@100W/2T 仅 70–137 高斯。
- MM0OPX Field Radio（Google Sheets 公开 VNA 数据）：2643 2:14 −0.44~−0.51dB 平坦 3.6–28MHz；3:21 低频 94–95% 但 28MHz 塌缩至 23%；FT240-43×3 86–89% 但 10m 66%；FT240-52×3 91–94%。
- Fair-Rite 数据表：43 = NiZn 抑制料（20–250MHz，tanδ/μᵢ=100×10⁻⁶，ρ=10⁵，μᵢ=800）；51 = NiZn 低损电感料（≤5MHz，tanδ/μᵢ=30×10⁻⁶，ρ=10⁹，μᵢ=350，特殊订料）；61 = NiZn 电感至 25MHz。**51 与 43 的 B@10Oe 相同（3500 高斯），51 的优势是损耗角与电阻率而非饱和。**
- N1FD 热模型：密封盒散热上限 ~6.2W；FT240-43 2:14 在 7MHz 连续平均功率上限 ~23W。
- 天线物理：端馈点=电流波节，λ 模第一腹点 ~5m@14MHz；加载 EFHW 波段强耦合（PA3HHO/ON7EQ/VK3IL/AI6XG）；铝壳/邻近导体可挪谐振 26–248kHz（Orderwire）；F4LEK 换抽头实测 143kHz 漂移；Sloper 低仰角偏向下坡端 1–3dB（KK4OBI 4NEC2）。

## 3. 裁决要点（完整版进 §4.1 文档）

| 级别 | 条目 |
|---|---|
| 证伪 | "51/43 均低损"；"51 用于 50–500MHz"；"3×51@14MHz 损耗 1.5–2dB/30%化热"（无出处且被类比数据反证）；"51 叠环饱和致驻波漂移"（B 距饱和两个数量级）；"1.85m 电流腹点/串 L 分频独立/四波段免天调"（波节位置错 + 已发表实例反证）；"换磁芯改变仰角与方向图"（损耗等比缩放）；"DG0SNC 研究"（文献不存在） |
| 平反 | 2643+2:14+补偿电容构型 ≈90% 级高效率（三源）；铝盒寄生电容下拉谐振（机理+量级均实证）；143 类大幅谐振漂移可信；"平底大汤碗"假宽带可被损耗阻尼造出；Sloper 下坡端低仰角偏向（与磁芯无关） |
| 修正 | 发热最恶区在 43 料是 20–10m（μ″主导）而非仅低频；主控变量是初级匝数非磁芯体积；补偿电容掩 VSWR 且增大高频芯损；"FT240-51" 非 Amidon 目录件（provenance 存疑） |
| 待实测 | 用户实物 3×51 盒 vs 2643 盒的 S21 逐带效率；2643 铝盒 60s/100W 温升；合盖/开盖谐振位移量；全库协议文档执行结果 |

**功率红线（正式版）**：2643251002/2:14/铝盒 —— FT8/CW：≤50W 直至 60s+红外枪热测通过（目标：盒壁 ≤55°C）；SSB/PSK（低占空比）：100W 可用；10m 100W 列为热测必测科目；80m 100W 禁用直至热测通过。
