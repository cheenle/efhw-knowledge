# 变换器 A/B 实测协议 — 3×FT240-51 vs 2643251002

> 2026-08-30 ｜ 配套裁决文档：[[core-swap-evidence-2026-08]] ｜ 执行人：BG1SB
> 现场记录文件：[[transformer_ab_log-2026-08]]（空白表直接填）｜ 判据速算：`scripts/ab_judge.py`
> 原则：所有效率数字以本协议实测为准，替换前一律标 *未实测*。

## P0 安全与准备

- 两盒同轴口均先接 50Ω 假负载试发 10W/10s 确认无打火；铝盒必须搭铁。
- 记录环境温湿度（影响散热解读）。
- 设备：天析/NanoVNA（需 S21 能力）、红外枪、秒表、无感负载 2450Ω（2×1.2kΩ 串联，实测阻值记入表）。

## P1 S21 透射效率（台架——裁决"1.5–2dB"与"90%+"之争）

1. 校准 S11+S21 至两根测试线端口。
2. 被测盒 50Ω 口 → VNA S11 端口；线端（天线口）→ 2450Ω 无感负载。
3. VNA S21 端口经另一只 49:1 参考变换器反推至该负载（参考件固定为 2643 盒；A/B 交换被测件消除参考误差）。
4. 连续波点频 3.6 / 7.1 / 14.2 / 21.3 / 28.5 MHz，记 |S21|(dB)。
5. **判据**：两盒相对差 <0.5dB → 外部报告"效率代差"叙事作废；结果回填裁决文档 §6。

> 可裁决：草稿"旧盒 1.5–2dB/30% 化热"、"新盒 90–93%"（文献侧 Owen/MM0OPX 已给 89–91%，本测补实物值）。

## P2 热实测（§4 功率红线的解除条件）

- 构型：2643 盒装入**实际铝盒**，输出接 2450Ω 负载。
- 电台 FT8 模式 100W × 60s + 静默 30s，共 5 周期；红外枪每 30s 记盒壁/磁芯可视部位温度。
- 科目：40m 与 10m **各一轮**（10m 验证 μ″ 主导发热预测）；同轮跑旧 3×51 盒作对照。
- **通过门**：盒壁稳态 ≤55°C 且期间 SWR 漂移 <0.2 → 在裁决文档 §4 表加实测行、解除对应红线。

## P3 自谐振与裸盒扫频

- VNA S11：从初级看进去 1–54MHz log 扫，记录第一自谐振点。
- 参考量级：2643 上 2T 绕组 SRF≈16MHz（Owen，[signal.report 转载](https://www.signal.report/2023/05/a-low-loss-efhw-transformer.html)）。
- 目的：解释 15m/10m 匹配结构差异；结果回填裁决文档 §5。

## P4 现场挂测（原斜拉几何、同尾线）

1. 校准至电台端（S1L2S3）；扫 3–30MHz，**存 log-mag Z 幅相**（SWR 在 1.0–1.5 区间分辨率不足）。
2. 记录 7.050 / 14.074 / 14.260 / 21.2 / 28.3 的深 V 底点频率、SWR 底值、SWR<1.5 / <2 带宽(kHz)。
3. **合盖/开盖对比**（开盖以扎带悬吊同位）：位移量=铝盒电容实测量。预判 30–150kHz（参照同芯变换器"手靠近挪 248kHz"的敏感度量级，见裁决文档 §3）。
4. 新旧盒各一轮；任一几何变量不一致则该轮作废。

> 可裁决：铝盒下拉说、"针尖带宽变窄"幅度、"下移 170kHz"量级。

## P5 CMC A/B（裁决"共模倾泻"之争）

- 三点位：CMC（FT240-43，RG-58 **7 匝**，依 `references/efhw_cmc.md` 规程）置于盒下 3m / 4.5m / 不接。
- 14.074 与 7.050 各扫一遍；发射时以手边场强探头/接收机靠近馈线外皮定性对比共模。
- **判据**：三点位 SWR 差 <0.2 → 机房 RFI 风险按现状可接受（USB 事件另行排查地环路，不赖磁芯）。

## P6 电台/调谐器行为（V3.0 或手调）

1. 14.074 与 14.260 各完成一次自动调谐。
2. 记录伺服目标步数、锁定耗时、重试次数（MRRC 日志导出）。
3. **判据**：重试 ≥2 次 = 高 Q 针尖窄于搜索步进 → 加密该带调谐表/降速；**勿剪线**（见裁决文档 §3 对 1.85m 串的否决）。
