# PCB 传输线参数 — 仿真级分析
# =================================
# 用于 KiCad 的 PCB 传输线计算工具 (TX-Line) 或手动解析计算
# 目标: 确保 50Ω 主线匹配, 高压轨阻抗受控, 无意外谐振

## 1. PCB 叠层参数

```
Layer Stack (双面板, FR4, 1.6mm):

  ┌──────────────────────────────────────┐  ← 顶层 F.Cu (35µm 铜)
  │  信号走线, MCU, 继电器, 电容阵列     │
  │  HV_BUS 大面积铺铜 (5mm 宽)          │
  ├──────────────────────────────────────┤
  │  FR4 介质层 (Er≈4.5 @ 14MHz)         │  1.6mm
  │  Tanδ ≈ 0.02 @ 14MHz                │
  ├──────────────────────────────────────┤
  │  底层 B.Cu (35µm 铜)                 │
  │  A区: 完整数字地平面                 │
  │  B区: 高压地铜排 + 密集过孔         │
  └──────────────────────────────────────┘
```

| 参数 | 值 | 备注 |
|------|-----|------|
| 板材 | FR-4, Tg≈135°C | 标准双面板 |

## 2. 关键传输线分析

### 2.1 RF 主线: SO-239 → SWR桥 → T200-2初级 (50Ω)

**微带线 (Microstrip)**:
- 顶层信号走线, 底层完整地平面
- 目标阻抗: 50 Ω ± 10%

```
计算 (TX-Line 或 Wheeler 公式):

  线宽 (W):     2.85 mm  (50Ω)
  铜厚 (t):     0.035 mm
  介质厚度 (h): 1.6 mm
  Er:           4.5

  Z₀:          50.1 Ω  ✓
  ε_eff:       3.45
  v_phase:      1.61 × 10⁸ m/s (0.54c)
  波长 @14MHz:  ~11.5 m (空间) → ~6.2 m (PCB上)
  λ/10:         62 cm → PCB 主线 << λ/10 → 无需阻抗控制!
```

> **结论**: RF 主线在 PCB 上的长度 (约 5-8 cm) 远小于 λ/10 (62 cm @ 14 MHz)。在 HF 频段, **PCB 走线不作为传输线工作**, 而是集总元件。50Ω 匹配由外部保证。

### 2.2 HV_BUS: T200-2 次级热端 → 天线端子 (高压)

**特性**:
- 线宽: 5.0 mm (最小)
- 对地间距: 5.0 mm (最小)
- 工作电压: ≤ 3KV peak

```
安全分析 (不涉及传输线效应, 因为长度 << λ):

  爬电路径: 5.0mm 空气间隙 ≫ 3KV
  FR4 介电强度: ~20 KV/mm
  → 5mm 间距在 3KV 下有 33× 安全裕度 ✓

  但对地电容不可忽略:
  C_stray ≈ ε₀ × ε_r × (Area / d)
    ≈ 8.85E-12 × 4.5 × (0.005×0.05) / 0.0016
    ≈ 6.2 pF

  在 30 MHz, 6pF 的阻抗:
  Xc = 1/(2π × 30MHz × 6.2pF) ≈ 856 Ω
  → 可能影响谐振回路的调谐! (并联在次级)
  → 固件自动扫描会补偿此寄生电容 ✓
```

### 2.3 共面波导 (CPW): 7 根继电器控制线穿过开槽

```
结构: 信号线 (F.Cu) 与两侧地铜箔共面 (同层)

  信号线宽:     0.5 mm (7根, 等间距)
  地间距 (gap): 1.5 mm (信号线到两侧地铜箔)
  铜厚:         0.035 mm
  Er:           4.5

  共面波导阻抗:  ~80-90 Ω (非关键 — 直流继电器控制信号)
  寄生电容/线:   ~2-3 pF (对两侧地铜箔)

  7根线总穿越宽度: 7×0.5 + 6×1.5 = 12.5mm << 115mm 槽长 ✓
```

### 2.4 过孔 (Via) 建模

| 过孔用途 | 孔直径 | 焊盘直径 | 数量 | 寄生电感 (每个) |
|---------|--------|---------|------|---------------|
| B区电容冷端 → 底层地 | 0.6mm | 1.2mm | ≥3/电容 | ~0.8 nH |
| MCU VSS → 底层地 | 0.5mm | 1.0mm | 2/Pin | ~1.0 nH |
| 继电器线圈 → 底层 | 0.8mm | 1.6mm | 1/继电器 | ~0.6 nH |

```
过孔寄生电感 (近似公式):
  L_via ≈ 5.08 × h × [ln(4h/d) + 1]  (nH, 尺寸单位 inch)
  
  对于 h=1.6mm(0.063"), d=0.6mm(0.024"):
  L_via ≈ 5.08 × 0.063 × [ln(4×0.063/0.024) + 1]
        ≈ 5.08 × 0.063 × [ln(10.5) + 1]
        ≈ 5.08 × 0.063 × 3.35
        ≈ 1.07 nH  (每个过孔)

  3 个过孔并联: 1.07/3 ≈ 0.36 nH  ← 对 HF 频段可忽略
  
  @ 30 MHz, XL = 2π × 30MHz × 0.36nH ≈ 0.068 Ω  ✓
```

## 3. 传输线工具使用 (KiCad / TX-Line)

### 3.1 KiCad 内置传输线计算器

```
PCB Editor → Tools → Transmission Line Calculator

推荐设置:
  Type:       Microstrip
  Er:         4.5
  TanD:       0.02
  Height:     1.6  mm
  Thickness:  0.035 mm
  Frequency:  30 MHz

  目标 Z₀:    50 Ω → 线宽 = 2.85 mm
  目标 Z₀:    75 Ω → 线宽 = 0.98 mm
  目标 Z₀:   100 Ω → 线宽 = 0.38 mm

  (这些仅在走线长度 > λ/10 时才有意义)
```

## 4. 完整性检查清单

| 检查项 | 方法 | 通过标准 |
|--------|------|---------|
| RF 主线回波损耗 | VNA S11 @ M座 | < -20 dB @ 1-30 MHz |
| HV_BUS 对地电容 | LCR 表 @ 100 kHz | < 10 pF |
| 过孔总电感 (电容冷端) | 只对极高频率 (< 100 MHz) 有意义 | < 5 nH |
| 控制线串扰 | 相邻线接 50Ω → 另一根测耦合 | < -40 dB @ DC-1 MHz |
| 地平面连续性 | 目视 + 万用表蜂鸣 | A区底层无断裂 ✓ |

---

> HF 频段 (1.8-30 MHz) PCB 走线关键结论:
> 1. 走线长度 << λ/10, 传输线效应可忽略
> 2. 阻抗匹配由集总元件 (变压器 + 电容阵列) 实现
> 3. 主要关注: 对地寄生电容、绝缘间距、过孔感抗
