# 方法: 解析计算 (Fourier 热传导 + 自然对流), 提供 CFD 边界条件。

## 3. 各元件温升计算

### 3.1 T200-2 磁芯 (HS1)

**磁芯损耗估算 (Steinmetz 方程)**:

```
Pv = k × f^α × B^β  (kW/m³)

Mix-2 材料参数 (据 Micrometals):
  k ≈ 5E-5  (经验系数)
  α ≈ 1.3  (频率指数)
  β ≈ 2.3  (磁通密度指数)

@ 7.1 MHz (最严条件):
  f = 7.1 MHz
  B_peak = 5.6 mT (100W)
  Ve = 2 × 17.3 = 34.6 cm³ (双叠)

Pv = 5E-5 × (7.1E6)^1.3 × (0.0056)^2.3
   = 5E-5 × 6.85E8 × 4.65E-6
   = 159 kW/m³

P_total = 159E3 × 34.6E-6 ≈ 5.5 W  (双叠总损耗)
```

**T200-2 温升计算**:

```
自然对流 + 辐射散热:
  磁芯表面积: A ≈ 2 × (π×50.8×14 + 2×π×(50.8²-31.8²)/4) ≈ 2×73.2 ≈ 146 cm²
  对流系数 h_conv ≈ 5 W/(m²·K) (自然对流, 盒内)
  辐射系数 h_rad  ≈ 5 W/(m²·K) (表面发射率 ε≈0.9)

  R_th_total = 1/((h_conv + h_rad) × A) ≈ 1/(10 × 0.0146) ≈ 6.85 K/W

  ΔT = P × R_th = 5.5 × 6.85 ≈ 37.7°C

  @ Ta=60°C → T_core = 60 + 37.7 ≈ 97.7°C
  @ Ta=25°C → T_core = 25 + 37.7 ≈ 62.7°C
```

> **结论**: 最恶劣情况 (100W RTTY/FM 连续 + 60°C 环境) 下磁芯温度接近 100°C。
> 低于居里温度 (300°C+) 和漆包线绝缘等级 (≥180°C) → **安全** ✓
> FT8 模式 (50% 占空比) → ΔT ≈ 19°C, T_core ≈ 79°C @ Ta=60°C → 更加安全 ✓

### 3.2 1812 MLCC (HS2 - C6/C7 大电容位)

```
谐振环流 I_cap ≈ 2.6 A RMS (见设计文档 §3.2)
每个 1812 MLCC 的 ESR ≈ 0.15 Ω (C0G, @ 14MHz)
并联分担: C6(2只) 各 1.3A, C7(3只) 各 0.87A

C6 位单只损耗: P = I²R = 1.3² × 0.15 ≈ 0.25 W
  1812 封装热阻 (PCB 铜箔散热): ≈ 40 K/W
  ΔT = 0.25 × 40 = 10°C
  T_max = 60 + 10 = 70°C << 125°C ✓

C7 位单只损耗: P = 0.87² × 0.15 ≈ 0.11 W
  ΔT = 0.11 × 40 = 4.4°C ✓
```

> 电容温升安全边际充足。关键风险是**凝露导致表面放电**, 而不是热烧毁。

### 3.3 LM7812 稳压器 (HS4)

```
P_diss = (Vin - Vout) × I_out
Vin ≈ 13.8V (Bias-T 输入)
Vout = 12V
I_out ≈ 150mA (7继电器 + MCU + 静态)

P_diss = (13.8 - 12) × 0.15 = 0.27 W

TO-220 不装散热片:
  R_th(JA) ≈ 50 K/W (自然对流)
  ΔT = 0.27 × 50 ≈ 13.5°C
  T_j = 60 + 13.5 = 73.5°C << 125°C (结温) ✓

结论: TO-220 无需外加散热片。
```

### 3.4 盒内空气温升

```
总盒内功耗: ~6W (最恶劣)
铝盒表面积: ~2 × (0.16×0.11 + 0.16×0.07 + 0.11×0.07) ≈ 0.073 m²
铝盒导热: k_al ≈ 237 W/(m·K) → 盒壁几乎等温

自然对流散热 (室外, 微风):
  h ≈ 10-15 W/(m²·K)
  R_th_box ≈ 1/(15 × 0.073) ≈ 0.91 K/W

盒内空气温升: ΔT = 6 × 0.91 ≈ 5.5°C

盒内温度: T_inside = Ta + 5.5°C
  @ Ta=60°C: T_inside ≈ 65.5°C ← 仍在所有元件额定范围内
```

## 5. CFD 仿真边界条件 (供参考)

如果使用 OpenFOAM / Ansys Icepak / FloTHERM 进行详细 CFD:

```
几何:
  - 铝盒: 160×110×70mm, 壁厚 3mm, 材料 ADC12 压铸铝
  - PCB: 140×90×1.6mm, FR4 (k=0.3 W/(m·K))
  - T200-2 磁芯: 外径 50.8mm×2, 等效为均匀发热圆柱
  - 继电器: 7个, 间距 15mm, 各 0.2W (调谐时)

边界条件:
  - 外部: 自然对流, h=10 W/(m²·K), Ta=60°C (极端)
  - 内部: 封闭空腔自然对流 (Rayleigh < 10³ → 传导主导)
  - 辐射: 各表面 ε=0.9 (铝氧化) / 0.3 (裸铝)
  - 太阳辐射: 800 W/m² (可选, 模拟暴晒)

发热元件:
  - T200-2: 5.5W 体发热 (均匀)
  - LM7812: 0.27W 点热源
  - MLCC: 10点各 0.1-0.25W

网格:
  - 最小尺寸: 1mm (盒壁), 最大: 5mm (空气域)
  - 边界层: 3层, 第一层 2mm
```

---

> **热分析结论**: 所有元件在最恶劣的 100W 连续发射 + 60°C 环境工况下均处于额定范围内。
> 唯一需注意的: 避免在烈日暴晒下的黑色铝盒中运行 (选浅色/原色铝盒)。
> 底部 1.5mm 呼吸孔同时帮助对流散热 (烟囱效应)。
