## 第一部分：装配指南

### 1.1 工具准备

| 工具 | 用途 | 必备/可选 |
|------|------|----------|
| 恒温烙铁 (60W+, 可调温) | 焊接 SOIC/1812/THT | 必备 |
| 0.5mm 焊锡丝 (63/37) | 精细焊点 | 必备 |
| 助焊剂 (免洗型) | SOIC 拖焊 | 必备 |
| 防静电手环 | PIC16F1938 防静电 | 必备 |
| 数字万用表 | 电压/导通/二极管测试 | 必备 |
| 镊子 (弯尖) | SMD 贴装 | 必备 |
| 放大镜/显微镜 | 焊点检查 | 推荐 |
| 热风枪 | SMD 拆修 | 推荐 |
| VNA (如 nanoVNA) | 磁环绕线验证/SWR桥调试 | 推荐 |
| 50Ω/100W 假负载 | 台架校准 | 推荐 |
| PICkit 3/4 | 固件烧录 | 必备 |

### 1.2 焊接顺序（关键！按顺序来）

```
第1步: A区低压电路 (先焊小件，后焊大件)
  ├─ 1.1 所有0805/1206电阻电容
  ├─ 1.2 BAT41检波二极管 (注意极性)
  ├─ 1.3 78L05 (TO-92)
  ├─ 1.4 PIC16F1938 SOIC-28 (注意Pin1方向!)
  ├─ 1.5 ULN2003A SOIC-16
  ├─ 1.6 LM7812 TO-220 (最后焊，不挡其他元件)
  │
  ├─ 1.X 检查: 上电测+5V和+12V
  │   用万用表测 78L05 OUT = 5V±0.25V
  │   用万用表测 LM7812 OUT = 12V±0.5V
  │   (此时通过ICSP口或L_bias焊盘临时供12-14V)
  │
第2步: SWR检测桥
  ├─ 2.1 绕制FT37-43磁芯: 每个磁环绕10T漆包线
  ├─ 2.2 焊接检波电阻网络 (50Ω负载, 10KΩ可调)
  ├─ 2.3 穿过RG-58同轴主线
  │
第3步: B区高压电路
  ├─ 3.1 7只G5Q-14继电器
  ├─ 3.2 10只1812高压电容
  ├─ 3.3 2.2MΩ静电泄放电阻
  │
第4步: T200-2磁环绕线 (详见1.3节)
  ├─ 4.1 绕线前清洁磁芯表面
  ├─ 4.2 双叠磁环并排 → 尼龙扎带预固定
  ├─ 4.3 2T初级 (粗线) + 13T次级 (同号线)
  ├─ 4.4 焊接到PCB对应焊盘
  ├─ 4.5 RTV硅胶固定线圈
  │
第5步: 端子、GDT、最后装配
  ├─ 5.1 焊接M座、天线端子、地网端子
  ├─ 5.2 焊接GDT (M座芯线对地)
  ├─ 5.3 安装ICSP排针
  └─ 5.4 最终目视检查
```

### 1.3 T200-2 双叠磁环绕线工艺（核心工序）

这是整个项目中最关键的装配步骤。绕线质量直接影响调谐器效率。

**准备工作**：

1. 取 2 只 T200-2 磁环，用酒精清洁表面
2. 将两磁环叠在一起（同心对齐），用尼龙扎带轻绑（不收紧）
3. 在磁环内径的绕线区域用细砂纸轻轻打磨 → 去除尖锐毛刺（防止刮伤漆包线绝缘层）

**初级 2T 绕线**：

```
步骤：
1. 取 0.8mm 漆包线约 30cm
2. 将线穿过双叠磁环中心 → 绕到磁环外 → 再穿回中心 → 绕到外
   这样穿过磁环中心 2 次 = 2T (2 turns = 穿过中心2次)
3. 初级两端留约 5cm 用于焊接
4. 初级均匀分布在磁环圆周约 1/3 的范围内
5. 用万用表验证: 初级两端导通 (约 0.1Ω)，
   初级与磁芯之间绝缘 (∞ Ω)
```

**次级 13T 绕线**：

```
步骤：
1. 取 0.8mm 漆包线约 120cm
2. 同样方式穿过磁环中心 13 次 = 13T
3. 次级匝间紧密排列，均匀覆盖磁环剩余 2/3 的圆周
4. 与初级并排但不交叉 (W8JI 并绕法)
   - 初级 2T 和次级 13T 沿磁环圆周并行排列
   - 匝间紧贴以最大化磁通耦合
5. 验证: 次级两端导通，
   初级-次级之间绝缘 (∞ Ω: 漆包线绝缘层隔离)
```

**匝数验证**：

```
用 VNA 或 LCR 表测量：
  初级电感 (次级开路): ≈ 2² × AL × 2(双叠) 
                      = 4 × 12nH × 2 ≈ 96 nH
  次级电感 (初级开路): ≈ 13² × 12nH × 2
                      = 169 × 12nH × 2 ≈ 4.06 μH
  (实测会因绕线松紧、分布电容而略有偏差，±20% 属正常)
```

**固定**：

- 收紧尼龙扎带 → 磁环+PCB 牢固绑定
- 在绕线区域薄涂一层 RTV 硅胶 → 防振动松脱
- 线圈引线端刮掉漆皮 → 上锡 → 焊到 PCB

### 1.4 SOIC 焊接技巧 (PIC16F1938, ULN2003A)

```
1. 在 PCB 焊盘上涂少量助焊剂
2. 对齐芯片 Pin1 (圆点/缺口) 与 PCB Pin1 标记
3. 先焊对角两脚固定芯片
4. 在一排脚上堆锡 → 用烙铁拖焊 (drag soldering)
5. 多余的锡桥用吸锡带清除
6. 显微镜检查: 无虚焊、无桥接
```

### 1.5 BAT41 检波二极管配对

```
1. 准备 5-10 只 BAT41
2. 用数字万用表二极管档 → 测量每只的 Vf
3. 记录数值 (如: 285mV, 291mV, 287mV...)
4. 选择 Vf 差值最小的两只 (< 5mV)
5. 标记为 D2 (FWD) 和 D3 (REV)
```

### 1.6 装壳

```
1. PCB 用 M3 尼龙隔离柱支撑在铝盒内 (距底壳 ≥5mm)
2. M座穿过铝盒面板孔 → 外部拧紧螺母 + 防水垫圈
3. 天线端子和地网端子穿过铝盒侧壁 → PTFE垫片内外各一片 → 不锈钢螺母锁紧
4. 电缆防水接头 PG9/PG7 拧入铝盒出线孔 → 电缆穿过后拧紧迫紧螺帽
5. 底部钻 1.5mm 呼吸孔 → 内侧贴 Gore-Tex 膜
6. 盒内放干燥剂包
7. 扣上盒盖 → 四角不锈钢螺丝对角线拧紧
```

## 第二部分：测试与校准

### 2.1 台架测试 1：直流供电验证

```
设备: 可调直流电源 (0-15V, 1A)

步骤:
1. 电源设 13.8V, 电流限制 0.5A
2. 正极接 L_bias 输出端 (模拟 Bias-T 供电)
3. 负极接 A区功率地
4. 上电 → 测量:
   a. LM7812 OUT = 12.0V ± 0.5V
   b. 78L05 OUT = 5.0V ± 0.25V
   c. MCU Pin20 (VDD) = 5.0V
   d. 电流消耗 (所有继电器断开): < 15 mA
5. 逐个闭合继电器 (用固件测试程序) → 每个继电器增加约 17mA
   7个全闭: 总电流 ≈ 15 + 7×17 ≈ 134 mA
6. 1N4007 防反接测试: 电源反接 → 电流为零 → 电路未损坏 ✓
```

### 2.2 台架测试 2：MCU 与固件

```
设备: PICkit 3/4, PC with MPLAB X IPE

步骤:
1. 连接 PICkit 到 ICSP 口 (Pin1=MCLR)
2. MPLAB X IPE → 选择 PIC16F1938 → 连接
3. 读取 Device ID → 确认芯片识别正确
4. 擦除 → 烧录 efhw_tuner_100w.hex → 验证
5. 上电 → 蜂鸣器 1 声短鸣 (正常) / 2声短鸣 (首次/新EEPROM)
6. LED 闪烁 1 次 → 系统自检通过
```

### 2.3 台架测试 3：电容阵列功能

```
设备: 万用表 (导通/电容档), 测试固件

步骤:
1. 烧录电容测试固件 (逐个继电器测试)
2. MCU 依次吸合 K1→K7, 每次间隔 1秒
3. 每次吸合时:
   a. 听到继电器"咔嗒"声 ✓
   b. 万用表蜂鸣档测对应电容热端对 HV_BUS 通路 ✓
4. 全部释放后:
   万用表电容档测 HV_BUS 对地 → 应在 10-30pF (PCB 杂散+继电器极间)
```

### 2.4 台架测试 4：SWR 桥校准

```
设备: 50Ω 假负载, 电台 (5W CW 模式), 万用表

步骤:
1. M座接 50Ω 假负载
2. 电台设 CW, 5W, 频率 14.100 MHz
3. 按下 PTT → 发射 5W 载波
4. 万用表测 SWR_FWD 测试点 (MCU RA0 前的 ADC) 直流电压
   → 应约 1.5-2.5V (取决于检波器分压比)
5. 调节 FWD 可调电阻 → 使 FWD ADC 读数为 512 (或目标值)
6. 万用表测 SWR_REV 测试点 (MCU RA1 前的 ADC) 直流电压
   → 在完美 50Ω 假负载时, REV 应接近 0V
7. 调节 REV 可调电阻 → 使 REV ADC 读数 < 5
8. 替换假负载为 100Ω (SWR=2.0 理论值) → 验证 REV 电压升高
9. 替换为 25Ω (SWR=2.0) → 同上
```

### 2.5 台架测试 5：高压耐压测试

```
设备: 100W 电台, 2.2kΩ/50W 功率电阻 (模拟 EFHW), 红外温度计

⚠️ 安全: 电阻会大量发热, 放在耐热绝缘表面上!

步骤:
1. M座接电台, 天线端子接 2.2kΩ/50W 功率电阻到地
2. 电台设 CW, 频率 14.100 MHz, 功率 50W
3. 手动设电容值为设计图纸中 14.1MHz 的预期值 (约 c_val=40-50)
4. PTT 按 10 秒 → 观察:
   a. B区无可见/可闻电弧放电 ✓
   b. 电台 SWR 表 SWR < 2:1 ✓
5. 增加到 100W CW → PTT 10 秒
6. 用红外温度计测:
   a. T200-2 磁环温升 < 10°C
   b. 高压电容温升 < 5°C
7. 增加持续时间到 60 秒 (100W) → 验证无热失控
```

### 2.6 现场验收测试

| 测试项 | 步骤 | 通过标准 |
|--------|------|---------|
| 调谐 SWR | 电台 5W CW, 触发自动调谐, 读取 SWR | < 1.2:1 |
| 100W 发射 | 100W CW 或 RTTY 60s | 无打火、无异常发热 |
| FT8 稳定性 | FT8 连续呼叫 30 分钟 | 调谐点不漂移，功率不衰减 |
| 换频段重调 | 切换频段 → 重新调谐 → 验证 SWR | SWR<1.5:1, 耗时<3s |
| 雨淋考验 | 正常安装后经历一次降雨 | 次日打开铝盒检查内部干燥 |
| 调谐重复性 | 同频段两次调谐 → 记录电容值 | 电容值相差 ≤2 步 |

## 第三部分：故障排查

### 3.1 上电无反应

| 检查项 | 方法 |
|--------|------|
| Bias-T 供电正常？ | 万用表测 L_bias 输出端对地电压 = 12-14V |
| LM7812 输出 12V？ | TO-220 中间脚对地 = 12V |
| 78L05 输出 5V？ | TO-92 输出脚对地 = 5V |
| MCU Pin20 (VDD) = 5V？ | 直接测芯片脚 |
| MCLR (Pin1) = 5V？ | 上拉电阻正常？ |
| 振荡器起振？ | 用示波器测 OSC1/OS2 或检查配置位 INTOSC+PLL |
| ICSP 口接触良好？ | 重新连接 PICkit 尝试读取 Device ID |

### 3.2 调谐永远 SWR>3:1

| 检查项 | 方法 |
|--------|------|
| 天线/Counterpoise 正确连接？ | 天线端子接 EFHW 导线, 地网端子接 2m 计数器导线 |
| 电容阵列在动作？ | 调谐过程中听继电器是否有"咔嗒"声 |
| 所有 7 个继电器都能吸合？ | 逐个测试, 万用表蜂鸣确认 |
| SWR 桥校准正确？ | 用 50Ω 假负载验证 FWD 和 REV 读数 |
| 磁环绕线正确？ | 测量初级电感 ~96nH, 次级电感 ~4μH |
| 工作频率在 40m-10m？ | 80m 暂时不支持 |
| 电容范围覆盖该频率？ | 检查 10pF-1997pF 范围是否足够 |

### 3.3 高功率时 SWR 飙升/不稳定

| 检查项 | 方法 |
|--------|------|
| 高压电容打火/击穿 | 目视检查 1812 电容有无裂纹/烧痕 |
| T200-2 磁芯发热严重 | 手摸 (小心!) 或红外测温 |
| 继电器触点烧蚀 | 取下继电器, 测 NC/NO 对 COM 接触电阻 (应 <0.1Ω) |
| 同轴连接松动 | 检查 M 座焊点无裂缝 |
| HV_BUS 爬电放电 | 黑暗环境中发射 100W, 看 B 区有无微光放电点 |

### 3.4 电容阵列不切换

| 检查项 | 方法 |
|--------|------|
| ULN2003A COM 接 +12V？ | **最常见故障原因!** 万用表确认 Pin9=12V |
| ULN2003A 输入信号？ | MCU RB0-RB6 写高时 = 5V, ULN2003A INx 对应 5V |
| 继电器线圈通电？ | 线圈两端应有 12V (ULN2003A OUTx 拉低时) |
| 继电器线圈开路？ | 断电后测线圈电阻 ≈ 720Ω |
| MCU 端口损坏？ | 写一个简单 LED 闪烁程序测试 RB0-RB6 输出 |

## 第四部分：维护计划

| 周期 | 维护项目 |
|------|---------|
| 每次 FT8 操作前 | 观察电台 SWR 表, 确认调谐正常 |
| 每月 | 检查铝盒底部呼吸孔是否堵塞 |
| 每 3 个月 | 更换盒内干燥剂包 |
| 每 6 个月 | 打开铝盒, 目视检查 PCB 无腐蚀, B区无放电痕迹 |
| 每年 | 用 nanoVNA 扫频, 确认调谐器 S21 插损 <0.5dB |
| 每 2 年 | 继电器触点寿命检查, 必要时更换 |
